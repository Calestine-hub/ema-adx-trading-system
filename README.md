# EMA-ADX Trading System

Development of a systematic trading system based on:

- 4H 200 SMA
- 15M 15 EMA / 50 EMA
- ADX and DI
- EMA pullbacks
- Candlestick confirmation
- Structured risk management

## Development Roadmap

### V2.X
TradingView live indicator and alerts.

### V3.X
Historical strategy tester and backtesting engine.

### EA
Future automated execution system after V2.X and V3.X have been sufficiently validated.
